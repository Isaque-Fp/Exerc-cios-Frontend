 Fundamentos de HTML & CSS

Repositório dedicado à prática e consolidação dos conceitos base de desenvolvimento front-end. 

 Tópicos Abordados
- **Estruturação Semântica:** Uso correto de tags do HTML5 (`<header>`, `<main>`, `<article>`, etc.).
- **Estilização e Layout (CSS3):** Box model, posicionamento (relativo, absoluto, fixo) e variáveis CSS.
- **Responsividade:** Media queries e adaptação para dispositivos móveis.
- **Componentes Práticos:** Construção e estilização de formulários e páginas de login.
